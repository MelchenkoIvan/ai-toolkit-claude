# Product Foundry --- Product Requirements Document (PRD)

## Project

**Product Foundry Website**

------------------------------------------------------------------------

## Goal

Create a premium landing page for **Product Foundry** --- a software
consultancy that helps founders transform ideas into production-ready
software products.

The website should generate trust, explain the service clearly, and
convert visitors into booked discovery calls.

Desired impression:

-   Premium
-   Technical
-   Modern
-   Fast
-   Trustworthy
-   AI-first
-   Startup-focused

Visitors should immediately understand that Product Foundry is a
boutique product engineering studio rather than a freelance portfolio.

------------------------------------------------------------------------

## Target Audience

### Primary

-   Startup founders
-   Non-technical founders
-   SaaS founders
-   Small software companies

### Secondary

-   SMEs building internal software
-   Companies needing technical leadership
-   Businesses replacing spreadsheets with custom software

------------------------------------------------------------------------

## Core Value Proposition

> We help founders launch software products faster by combining senior
> engineering expertise with AI-assisted development.

------------------------------------------------------------------------

## Services

### Primary Service --- From Idea to Product

Help founders transform an idea into a production-ready MVP.

Includes:

-   Discovery
-   Requirements gathering
-   Solution architecture
-   UX implementation
-   Backend development
-   Frontend development
-   Cloud deployment
-   AI integrations
-   Production launch

### Architecture Review

Deliverables:

-   Architecture assessment
-   Risk analysis
-   Technical debt review
-   Scalability recommendations
-   Cost optimization suggestions

### Technical Advisory

Engineering partnership including:

-   Architecture decisions
-   Code reviews
-   Team mentoring
-   Development planning
-   AI adoption strategy

------------------------------------------------------------------------

## Positioning

### We are NOT

-   A generic software house
-   An outsourcing company
-   A freelance developer

### We ARE

**A boutique product engineering studio helping founders build and
launch software products.**

------------------------------------------------------------------------

## Key Messages

Visitors should understand that:

-   We build products, not just software.
-   We move quickly without compromising quality.
-   AI accelerates delivery, while experienced engineers make technical
    decisions.
-   We think like founders.
-   We focus on business outcomes.

------------------------------------------------------------------------

## Design Principles

Inspired by:

-   Linear
-   Vercel
-   Stripe
-   Raycast
-   Clerk

Design characteristics:

-   Minimalistic
-   Premium
-   Large whitespace
-   Elegant typography
-   Rounded components
-   Subtle gradients
-   Soft animations
-   Engineering-oriented aesthetic

Avoid:

-   Generic stock photography
-   Overly flashy effects
-   Marketing clichés
